Grid Data Models

NLR's Grid Data Model (GDM) provides a standard structure, so data can be read, shared, and reused seamlessly across planning, building, and operations.

Grid Data Models unlock digitalization benefits

GDM helps accelerate distribution utilities to realize the potentials of digitalization:

  • Loss reduction
  • Improved voltage and power quality
  • Enhanced DER integration
  • Optimized capacity expansion

GDM addresses key challenges in digitalization:

  • Data integrity
  • Process interoperability
  • Integration and scaling
